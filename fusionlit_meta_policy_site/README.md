# Fusionlit Games Meta App Website

Static website intended for GitHub Pages.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Your pages will be:

- `/`
- `/privacy-policy.html`
- `/data-deletion.html`
- `/terms.html`

Use the exact public Privacy Policy URL in Meta App Settings → Basic.
Use the exact public Data Deletion URL in the corresponding Meta field.

Do not put Facebook access tokens, `.env` files, API secrets, or other credentials in this repository.
